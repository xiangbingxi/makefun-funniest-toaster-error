## Entry

```
ERROR 409: Bread ejected successfully; toast remains a matter of opinion.
```

73 characters, within the 120-character limit.

## How it works

Run `main.py`. It writes the entry text, exactly as above, to `/output/entry.txt` (UTF-8, no trailing newline), then reads the file back and checks it matches byte for byte, exiting with an error if it does not. It reads no external files and uses no network.
